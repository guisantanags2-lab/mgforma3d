# MG Forma 3D — Portfólio

Site portfólio da **MG Forma 3D** — decoração e utilidades em impressão 3D (São José do Rio Preto – SP).
Instagram: [@mgforma3d](https://www.instagram.com/mgforma3d/)

## Como adicionar novos trabalhos
1. Abra o post no Instagram e copie o link (ex.: `https://www.instagram.com/p/XXXXXXXXXXX/`).
2. Edite `posts.js` e cole o link no topo da lista.
3. Salve (commit). O GitHub Pages atualiza o site em ~1 minuto.

## Publicação
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
